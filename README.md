# usage-band

Mod per Claude Code: una banda sopra il prompt con memoria della chat, costo, uso 5 ore / settimana, durata della sessione e cache calda, con barre grafiche sul desktop.

## Installazione

Dal prompt di una sessione da terminale:

```
/plugin install usage-band --marketplace kevinilcondor/usage-band
```

Da una shell:

```
claude plugin install usage-band --marketplace kevinilcondor/usage-band
```

Nell'app desktop: clic su + accanto al prompt, poi Plugins, Add marketplace con `kevinilcondor/usage-band`, poi Add plugin.

Il repository è privato: serve l'accesso in lettura su GitHub e una credenziale git per github.com già configurata sul computer.
